# Amaranth10 MCP

더존 아마란스10 그룹웨어를 Claude 등 MCP 클라이언트에서 사용하는 서버입니다. 메일·일정·전자결재를 확인하고, 메일을 보내거나 회의실을 예약하고 개인 일정을 관리할 수 있습니다.

“안 읽은 메일을 요약해 줘.” · “내일 오후에 비어 있는 회의실을 찾아 줘.” · “남은 연차를 알려 줘.”

[릴리스](https://github.com/nubison/amaranth10-mcp/releases) · [CI](https://github.com/nubison/amaranth10-mcp/actions/workflows/ci.yml) · [상세 가이드](docs/guide.md)

## 설치

그룹웨어 주소와 아이디·비밀번호가 필요합니다. OTP 등 추가 인증이 필요한 계정은 지원하지 않습니다.

### Claude Code

Node.js 20 이상과 Git이 필요합니다.

```bash
npx -y github:nubison/amaranth10-mcp#v0.8.1 setup
```

주소·아이디·비밀번호를 입력하고 Claude Code 등록에 동의한 뒤, Claude Code를 새로 열면 됩니다. 업데이트하려면 버전 태그를 바꿔 setup을 다시 실행하세요.

### Claude Desktop (macOS)

[최신 릴리스](https://github.com/nubison/amaranth10-mcp/releases/latest)의 `.mcpb` 파일을 열어 설치하고 그룹웨어 접속 정보를 입력하세요. Node.js는 별도로 설치하지 않아도 됩니다.

서버·컨테이너는 [환경변수로 설정](docs/guide.md#환경변수로-설정)할 수 있습니다.

## 제공 도구

계정에 허용된 범위에서 동작합니다. ✓는 지원, —는 미지원입니다.

| 기능 | 조회·검색 | 등록·예약 | 수정 | 삭제·취소 | 참고 |
|---|:---:|:---:|:---:|:---:|---|
| 메일 | ✓ | ✓ | ✓ | ✓ | 보내기, 안 읽음·읽음 표시, 휴지통으로 이동. 안 읽은 메일 본문 열람 시 읽음 처리 |
| 게시판 | ✓ | — | — | — | 본문 열람 시 조회수 증가 |
| 자원·회의실 | ✓ | ✓ | — | ✓ | 본인 예약만 취소 가능. 참석자에게 알림이 갈 수 있음 |
| 일정 | ✓ | ✓ | ✓ | ✓ | 개인 일정만 변경, 일부 일정은 제한. 참석자 추가 시 초대 알림 발송 |
| 전자결재 | ✓ | — | — | — | 미결 문서의 열람 여부가 기안자에게 표시될 수 있음 |
| 조직도 | ✓ | — | — | — | 직원 검색·부서원 조회 |
| 연차·휴가 | ✓ | — | — | — | 잔여 연차·신청 내역 조회 |
| 알림 | ✓ | — | — | — | 최근 알림 조회 |

- 메일 보내기·삭제와 예약·일정 변경은 미리보기 확인과 승인 후 실행됩니다. 읽음·안 읽음 표시와 조회수 변경에는 승인 절차가 적용되지 않습니다.
- 변경 요청은 자동 재시도하지 않습니다. 결과가 불확실하면 그룹웨어에서 처리 여부를 먼저 확인하세요.
- 날짜와 시각은 한국 시간 기준입니다. 출퇴근·근무 기록 조회, 휴가 신청, 전자결재 작성·승인은 지원하지 않습니다.

[도구 목록과 메일·일정 변경 제한](docs/guide.md#도구-목록)은 상세 가이드에서 확인할 수 있습니다.

## 접속 정보

setup은 macOS 키체인에 비밀번호를 보관합니다. **다른 OS나 키체인 저장 실패 시에는 파일에 평문으로 저장합니다.** Desktop 확장은 Claude Desktop에서 관리합니다.

비밀번호를 변경했다면 setup 또는 확장 설정을 갱신하세요. 로그인 실패 시 같은 비밀번호로 반복 시도하면 계정이 잠길 수 있습니다. [저장·삭제 방법과 문제 해결](docs/guide.md#접속-정보-관리)
